## Publicación
Puedes desplegar esta carpeta directamente en:
- Vercel
- Netlify
- GitHub Pages

No requiere build ni dependencias.

## Antes de publicar con dominio propio
Cuando tengas la URL definitiva, conviene agregar:
- `<link rel="canonical" href="https://tu-dominio.cl/">`
- `og:url`
- una imagen `og:image` de vista previa para LinkedIn/WhatsApp.
